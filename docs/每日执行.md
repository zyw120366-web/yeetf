# ye 每日执行

完整执行说明只维护在 [ye每日执行Skill](../skills/ye-daily-execution/SKILL.md)，本页是用户入口，不复制命令和参数。

日常流程：核对新成交 → 更新行情与逐条审核 → 计算持仓和候选 → 校验订单权限 → 交付日报并同步。

- 已确认持仓照实分析；资金未知只影响能否放行订单及账户收益计算，不省略可完成的观察日报。
- READY表示完整计划通过；SELL_ONLY表示仅核验过的卖出；BLOCKED表示订单未放行。报告生成成功不等于允许交易。
- 真实成交、取消和出入金优先于假定执行；不能把回测仓位当真实账户。
- 正常与受阻日报共用一个生成器；完整观察日报也冻结当日行情。交付检查核验账户、目标、订单、日期、哈希和页面链接，并直接输出可用于回复的摘要与Markdown链接。
- 用户只需看日报开头的动作、收益与理由。已有成交不重复确认；补充实际与计划的差异即可。
- 日报不设500字下限，不安排每日研究；收盘宝只按可取得的实际回单核验。
