# ye 每日执行

完整执行说明只维护在 [ye每日执行Skill](../skills/ye-daily-execution/SKILL.md)，本页是用户入口，不复制命令和参数。

日常流程：核对新成交 → 更新行情与逐条审核 → 计算持仓和候选 → 校验订单权限 → 交付日报并同步。

- 已确认持仓照实分析；资金未知只影响能否放行订单及账户收益计算，不省略可完成的观察日报。
- READY表示计划通过；如标记sale_proceeds_only，则只允许用本次卖出净款先卖后买，历史现金与账户总收益仍待核。SELL_ONLY表示仅核验过的卖出；BLOCKED表示订单未放行。报告生成成功不等于允许交易。
- 卖出款换仓：原持仓必须全部实际成交，核对实际卖出费用和券商卖后可用资金，再按实际买价、费用及100股整数倍计算；未知旧现金不计预算。部分成交、未成交或净款未核不买新ETF，不能假定完整换仓。实际回报由正式成交核对入口处理并防重复记账。
- 真实成交、取消和出入金优先于假定执行；不能把回测仓位当真实账户。
- 正常与受阻日报共用一个生成器；入口一次交付摘要及Markdown链接，无需另跑交付命令。保留账户、目标、订单、日期和页面一致性检查；只绑定当日计划与日报，不反复扫描代码和历史行情。完整价格观察也冻结当日行情。
- 用户只需看日报开头的动作、收益与理由。已有成交不重复确认；补充实际与计划的差异即可。
- 日报不设500字下限，不安排每日研究；收盘宝只按可取得的实际回单核验。
