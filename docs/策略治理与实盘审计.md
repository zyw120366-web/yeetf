# 策略治理与实盘审计

本文件定义唯一正式的 ye 策略在实盘前后的变更、运行与成交核对纪律。它不新增任何买卖因子。

## 规则冻结

- 正式规则真源始终是 `config/ye_strategy.yaml`，当前正式标识为 `YE-FORMAL-2026-07-19`。
- 每日执行不得修改买卖规则、ETF池、成本、仓位规则或情绪审核放行条件。
- 新想法先登记在 `config/research_hypotheses.yaml`，只能在独立研究中测试；只有通过独立样本外验收且经用户确认，才可改动正式规则。

## 每日运行卡

每个收盘后运行都会在 `results/audit/YYYY-MM-DD_live_run_card.json` 写入：规则标识、订单结论、情绪审核覆盖、上线状态、运行清单哈希、当前计划的成交确认状态和下一交易日需完成的事项。运行卡只记录事实，不生成或覆盖订单。

## 计划与成交对账

订单计划不是成交。若前一份计划含买入或卖出，下一次收盘运行前必须：

1. 将真实成交或未成交结果写入 `results/live/YYYY-MM-DD_actual_fills.json`；格式见 skill 的 `references/execution-confirmation-schema.md`。
2. 运行 `scripts/reconcile_actual_fills.py --date YYYY-MM-DD`。
3. 只有生成 `results/audit/YYYY-MM-DD_execution_reconciliation.json` 且状态为 `confirmed`，后续新开仓计划才可获得 `READY`。

首日或前一份计划只有持有/空仓时，不需要成交回单。任何缺失、部分成交或用户未确认都必须如实标记，不得把计划当作持仓。
