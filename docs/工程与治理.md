# 工程与治理

本文件只说明项目边界、真源、变更纪律和验收要求，不重复策略参数或每日操作。

## 唯一真源

- 正式规则：`config/ye_strategy.yaml`
- ETF池、日期与执行成本：`config/market.yaml`
- 情绪审核：`config/sentiment.yaml`、`config/sentiment_review_policy.yaml`
- 治理与授权：`config/strategy_governance.yaml`
- 实盘账户：`results/live/account_state.json`
- 当前交接：`RESEARCH_STATUS.md`
- 长期记忆和变更记录：`RESEARCH_MEMORY.md`

文档是解释层。出现冲突时按上述真源处理，不用手工文字覆盖配置或账户文件。

## 模块边界

- `src/etf_rotation/`：数据、信号、执行、回测、情绪和评价核心。
- `run_strategies.py`：重建正式ye与etfwin参考结果。
- `scripts/run_after_close.py`：唯一每日编排入口。
- `scripts/`：采集、审核提交、订单、对账、日报、页面、放行和审计工具。
- `experiments/`：研究与月度复盘；禁止被每日入口引用。
- `dashboard/scripts/`：从正式结果生成三份静态页面。
- `skills/ye-daily-execution/`：每日执行Skill真源。

## 输出边界

- `results/ye_strategy/`：正式回测、成交、权重和交易审计。
- `results/etfwin_reference/`：同数据口径参考，不参与实盘。
- `results/comparison/`：跨策略指标和当日全池排名。
- `results/live/`：账户、订单计划、日报和放行状态。
- `results/audit/`：按日期保存的运行清单、运行卡和必要成交对账；不保存研究结果或`latest`副本。
- `results/research/`：可再运行的研究摘要和月度报告。
- `dashboard/public/`：页面构建产物；`outputs/`：给用户直接打开的中文文件名副本。

## 规则冻结与研究隔离

- 每日执行不得修改买卖规则、ETF池、成本、仓位或审核放行条件。
- 当前池架构冻结为45只核心冠军＋6只挑战者空档补位。新增覆盖不进入核心前五混排；核心候选拥有第一买入权，挑战者只在核心无候选时参与，核心候选恢复即让位。核心/挑战者调整只允许通过正式版本变更。
- 新想法只能登记在 `config/research_hypotheses.yaml`，并在独立脚本中预先写明假设、区间、对照和失败条件。
- 只有独立验证通过且用户明确确认后，才能更新正式配置、治理标识、当前状态和项目记忆。
- 月度复盘只比较实盘与冻结基线，不生成订单、不自动调参。

## 计划、成交与AI证据

- 订单计划不是成交。需要买卖时才生成 `*_actual_fills.template.json`；无订单不制造空模板。
- 前一买卖必须生成状态为`confirmed`的成交对账，后续新开仓才可`READY`。
- 资讯队列逐行审核；ETF有效映射必须有冻结文本中的专属关键词。
- 同日同公司跨来源每行保留，但下游特征只计一次。
- 从2026-07-23信号日起，审核必须保存模型可见信息及审核协议、配置、schema的SHA-256；缺失即关闭新仓。

## 项目卫生

- `RESEARCH_STATUS.md`只写当前快照；`RESEARCH_MEMORY.md`只写持久结论和变更记录。
- 不跟踪缓存、ZIP、scratch、无引用副本和可再生的详细研究中间表。
- 每次实质修改必须更新项目记忆；正式版本或数据日期变化时同步更新当前状态。
- 运行 `PYTHONPATH=.:src python3 scripts/validate_project_hygiene.py` 检查版本、日期、文档、冗余文件和研究隔离。

## 验收

```sh
PYTHONPATH=.:src python3 scripts/validate_project_hygiene.py
PYTHONPATH=.:src python3 -m pytest -q
PYTHONPATH=src python3 scripts/validate_live_readiness.py --date YYYY-MM-DD
```

正式结果必须与冻结校验值一致，审核覆盖率必须为100%，三个HTML必须生成，运行清单和运行卡必须与同日配置及结果相互校验。
