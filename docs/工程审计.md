# 工程审计

## 模块边界

- `src/etf_rotation/data.py`：价格面板与标的代码。
- `src/etf_rotation/execution.py`：上市期、流动性资格、唯一成本模型和区间指标。
- `src/etf_rotation/sentiment.py`：已审核情绪特征的读取与日期可用性。
- `src/etf_rotation/sentiment_ai.py`：逐行审核结构、直接ETF映射、跨源事件键与审核协议指纹。
- `src/etf_rotation/etfwin.py`：etfwin 公开规则代理的技术特征与持仓状态机。
- `src/etf_rotation/ye.py`：当前 ye 增强选择、退出保护与冷却规则。
- `src/etf_rotation/backtest.py`：T+1 开盘成交、整手、成本、涨跌停和流动性执行。
- `src/etf_rotation/evaluation.py`：完整交易回合与失败操作标签。
- `run_strategies.py`：只负责编排正式 ye 与 etfwin 同快照运行和标准结果输出。
- `dashboard/scripts/build_ye_strategy_html.py`：只读取正式结果，生成三个静态页面。

研究脚本不得被每日入口引用。正式订单、回测、交易审计和 HTML 均读取 `results/ye_strategy` 的同一组信号与成交结果。

## 正式输出

- `results/ye_strategy/`：ye 净值、成交、权重、诊断、完整交易和审计。
- `results/etfwin_reference/`：etfwin 同快照对照。
- `results/comparison/`：两策略指标、净值、年度结果和当日全池排名。
- `results/live/`：当日订单、日报和上线检查。
- `results/audit/`：逐日 SHA-256 运行清单。
- `config/strategy_governance.yaml`：正式规则冻结、变更放行和实盘审计边界。
- `config/research_hypotheses.yaml`：独立研究假设登记；不参与每日信号。
- `results/audit/*_live_run_card.json`：每日可复现的规则、审核、计划与放行卡。
- `results/audit/*_execution_reconciliation.json`：真实成交与计划对账结果。
- `results/research/strategy_ablation/`：四档组件消融；只供归因研究。
- `results/research/monthly_review/`：每月一次的实盘与冻结基线对照。
- `results/research/universe_audit/`：当前45只池的历史上市、流动性和价格连续性审计，以及无法观察退市产品的限制声明。
- `dashboard/public/` 与工作区 `outputs/`：策略、日报、回测三个静态 HTML。

## 当前回归基准

截至2026-07-22，正式 ye 同口径结果为累计收益569.79%、年化26.63%、最大回撤-22.18%、失败操作率68.75%。审核证据收紧没有改变该快照的正式权重与绩效，但消除了泛商品资讯对豆粕ETF的错误热点计数。

## 验收要求

Python 测试必须全部通过；正式指标必须与 `config/ye_strategy.yaml` 的冻结校验值一致；情绪审核必须完整；运行清单必须包含所有关键文件；三个 HTML 必须能在本地浏览器打开、导航一致、无研究过程或候选描述。
